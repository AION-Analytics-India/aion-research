# Contributing

Thanks for taking the time. Issues and pull requests are both welcome.

## Reporting a problem

Open an issue describing what you expected, what happened, and how to reproduce
it. If the problem is a wrong value rather than a crash, include the input and
the source you are checking against. Corrections backed by a primary source are
the most useful thing you can send us.

## Pull requests

1. Fork and branch from `main`.
2. Add a test for behaviour you change or add.
3. Run the test suite before opening the PR.
4. Keep to PEP 8, four spaces, type hints where they clarify intent.
5. One logical change per pull request.

## Scope

This project is infrastructure. It is built to inform, not to advise, and it
does not issue trading recommendations. Contributions that turn outputs into
buy or sell signals are out of scope.
